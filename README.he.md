# VybeKiit

[![CI](https://github.com/VybeKiit/vybekiit/actions/workflows/ci.yml/badge.svg)](https://github.com/VybeKiit/vybekiit/actions/workflows/ci.yml)

VybeKiit היא ערכת התחלה בתשלום ל־vibe coders: אנשים שיודעים מה הם רוצים לבנות, משתמשים בעוזר קידוד AI, ולא רוצים ללמוד קוד לפני שהם יכולים לשלוח מוצר.

אתם מתארים את המוצר. העוזר עוקב אחרי הוראות הערכה, מגדיר את האפליקציה, מתקן מה ששבור, ומלווה אתכם בצעדים המעטים שרק אתם יכולים לעשות.

> **סטטוס:** עבודה פעילה על הערכה. נקודת ההתחלה של אפליקציית האינטרנט, הוראות לעוזר והקוד של הערכה כבר במקום. זרימת הרכישה והגישה בשידור חי עדיין בהשלמה.

## פרומפט מוכן לכלי הקידוד שלכם

פתחו את הפרויקט ב־[Claude Code](https://code.claude.com/docs/en/overview), [Codex](https://developers.openai.com/codex/quickstart), [Cursor](https://cursor.com/docs), Grok, Kimi, Roo, [Zed](https://zed.dev/), Kiro, [GitHub Copilot](https://github.com/features/copilot), או בכל כלי קידוד AI אחר, והדביקו:

```text
אני vibe coder לא־טכני שמשתמש ב־VybeKiit.

קרא קודם את AGENTS.md ואת language.md.
דבר אליי בשפה פשוטה. צעד אחד בכל פעם. אל תיתן לי חומת פקודות.
אל תצפה שאבין את הקוד.

עזור לי לעבוד עם פרויקט ערכת ההתחלה הזה:
1. הסבר בקצרה למה התיקייה הזו מיועדת.
2. תגיד לי מה הצעד הבא היחיד שאני צריך לעשות.
3. אם צריך הגדרה, עשה אותה בעצמך כשאפשר, ונווט אותי רק בלחיצות שרק אני יכול לעשות.

התחל עכשיו: הגדר אותי כך שאוכל לבנות עם עוזר AI בלי ללמוד את הקוד.
```

## מתחילים כאן

אחרי שיש לכם גישה ל־VybeKiit, צרו את נקודת ההתחלה של האפליקציה (העוזר יכול להריץ את זה בשבילכם):

```bash
npx vybekiit setup
npx vybekiit create app --web
```

אחר כך פתחו את התיקייה החדשה בכלי הקידוד והדביקו את הפרומפט למעלה, או פשוט אמרו:

> **הגדר לי את האפליקציה.**

העוזר קורא את ההוראות שצורפו לאפליקציה וממשיך משם, צעד אחד בכל פעם.

## מה אפשר לבקש

אין צורך ללמוד איך הקוד עובד קודם. התחילו בבקשות פשוטות:

- **"הגדר לי את האפליקציה."** הגדרה ראשונה.
- **"הוסף תשלומים."** להתחיל לקחת כסף.
- **"הוסף התחברות ושמירת מידע."** חשבונות ומידע שמור.
- **"משהו שבור."** בדיקה ותיקון.
- **"שים את האפליקציה באוויר."** לפרסם את הגרסה העדכנית.

VybeKiit בנויה כך שהעוזר מחליט על הצעדים הטכניים ומסביר רק מה שאתם צריכים לעשות.

## מה הערכה מטפלת בו

- נקודת התחלה אמיתית לאפליקציית אינטרנט.
- הוראות לעוזרי קידוד AI.
- מסלולים לתשלום, התחברות, מידע שמור, ועלייה לאוויר.
- בדיקה מקומית כדי שהעוזר יוודא שהאפליקציה תקינה לפני שממשיכים.
- חלקים משותפים שהערכה יכולה לשפר לאורך זמן.

מצפים מכם לתאר את המוצר, לבדוק את התוצאה, ולאשר צעדים בחשבון או בדפדפן כשצריך. לא מצפים שתבינו את הקוד לפני שהאפליקציה מתקדמת.

## מה צריך

נדרש [Node.js](https://nodejs.org/en) בגרסה 20 ומעלה. פקודת ההגדרה משתמשת בכלי העזר של VybeKiit.

כדי לקבל את קבצי האפליקציה שרכשתם, VybeKiit משתמש בכלי גישה קטן מ־GitHub. אם הוא עדיין לא מוכן, הערכה אומרת מה להתקין או לאיזה חשבון להתחבר.

## לסוכנים ולמתחזקים

התיקייה הזו גם מחזיקה את ההוראות והקוד לבניית הערכה עצמה. אם אתם סוכן או מתחזק בתוך הפרויקט, קראו קודם:

- [AGENTS.md](./AGENTS.md)
- [CONTEXT.md](./CONTEXT.md)
- [CODE-STYLE.md](./CODE-STYLE.md)
- [LANGUAGE.md](./LANGUAGE.md)

פקודות שימושיות למתחזקים:

```bash
pnpm install
pnpm build
pnpm test
pnpm typecheck
pnpm lint
```

כלי המתחזקים משתמשים ב־[pnpm](https://pnpm.io/) וב־[Turborepo](https://turborepo.com/docs).
