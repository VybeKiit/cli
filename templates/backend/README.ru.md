# Часть за кулисами

Собрано с **VybeKiit**. Это всегда включённая часть, которая делает работу за кулисами: сохраняет данные, принимает платежи, отправляет письма и даёт людям входить. Телефонное приложение и дополнение для браузера используют эту часть, чтобы оставаться простыми и безопасными.

Код читать не нужно. Скажите AI‑помощнику, что хотите построить.

## Готовый промпт для AI‑инструмента

Откройте проект в [Claude Code](https://code.claude.com/docs/en/overview), [Codex](https://developers.openai.com/codex/quickstart), [Cursor](https://cursor.com/docs), Grok, Kimi, Roo, [Zed](https://zed.dev/), Kiro, [GitHub Copilot](https://github.com/features/copilot) или любом другом AI‑инструменте и вставьте:

```text
Настрой часть за кулисами.

Я нетехнический vibe coder. Прочитай AGENTS.md и language.md.
Говори простым языком. По одному действию. Переводи любые ошибки.
Празднуй прогресс. Не сыпь на меня технические шаги.

Начни с первой настройки, пока эта всегда включённая часть не будет готова для телефонного приложения или дополнения для браузера.
```

## Начните здесь

Откройте эту папку в AI‑инструменте и скажите:

> **«Настрой часть за кулисами.»**

Помощник продолжит сам. Он читает инструкции, проводит вас по шагам, которые можете сделать только вы (по одному, простым языком), и готовит эту часть.

## Что можно попросить

- **«Настрой часть за кулисами»**: первая настройка.
- **«Пусть люди входят»**: аккаунты, которыми могут пользоваться телефонное приложение или дополнение для браузера.
- **«Запоминай данные»**: место, где приложение по‑настоящему сохраняет информацию.
- **«Добавь платежи»**: начать принимать деньги.
- **«Отправляй письма»**: приветствия, чеки и коды для входа.
- **«Что‑то сломано»**: помощник проверит и починит.

Всё. Техническое берёт на себя помощник.
