# Ваше дополнение для браузера

Собрано с **VybeKiit**. Это стартовая точка дополнения для браузера: маленькое окно, которое люди открывают из браузера. Код читать не нужно. Скажите AI‑помощнику, что хотите построить.

Вход, сохранённая информация и платежи живут на **вашем веб‑приложении**. Дополнение общается с ним и никогда не хранит секретные настройки.

## Готовый промпт для AI‑инструмента

Откройте проект в [Claude Code](https://code.claude.com/docs/en/overview), [Codex](https://developers.openai.com/codex/quickstart), [Cursor](https://cursor.com/docs), Grok, Kimi, Roo, [Zed](https://zed.dev/), Kiro, [GitHub Copilot](https://github.com/features/copilot) или любом другом AI‑инструменте и вставьте:

```text
Настрой моё дополнение для браузера.

Я нетехнический vibe coder. Прочитай AGENTS.md и language.md.
Говори простым языком. По одному действию. Переводи любые ошибки.
Празднуй прогресс. Не сыпь на меня технические шаги.

Начни с первой настройки, пока я не смогу открыть предпросмотр дополнения на компьютере.
```

## Начните здесь

Откройте эту папку в AI‑инструменте и скажите:

> **«Настрой моё дополнение для браузера.»**

Помощник продолжит сам. Он читает инструкции, проводит вас по шагам, которые можете сделать только вы (по одному, простым языком), и запускает дополнение.

## Что можно попросить

- **«Настрой моё дополнение для браузера»**: первая настройка.
- **«Добавь вход»**: пусть люди входят (через веб‑приложение; дополнение не хранит закрытые ключи). Скажите **«Вход через Google»** для входа в один тап.
- **«Сохраняй данные»**: хранить то, что создают пользователи (на веб‑приложении).
- **«Добавь платежи»**: начать принимать деньги (на веб‑приложении).
- **«Опубликуй в магазине дополнений»**: отправить последнюю версию.
- **«Что‑то сломано»**: помощник проверит и починит.

Проверки безопасности (замедление злоупотреблений, блокировка плохих запросов) живут на **вашем веб‑приложении**. Дополнение обращается к нему; настраивать это внутри дополнения не нужно.

Всё. Техническое берёт на себя помощник.
