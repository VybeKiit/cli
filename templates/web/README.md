# Your app

Built with **VybeKiit**. You don't need to read code to use this — just open the project in Claude
or Codex and tell it what you want to build.

## Start here

Open this folder in your AI coding tool and say:

> **"Set up my app."**

Your agent takes it from there — it reads its instructions, walks you through the few steps only you
can do (one at a time, in plain language), and gets your app online.

## Things you can ask for

- "Set up my app" — first-time setup, ends with your app online.
- "Add payments" — start taking money.
- "Add sign-in and save data" — accounts and storage.
- "Something's broken" — your agent runs a checkup and fixes it.
- "Put my app online" — publish the latest version.

That's it. Everything technical is handled for you.
