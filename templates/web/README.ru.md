# Ваше приложение

Собрано с **VybeKiit**. Это стартовая точка веб‑сайта, который люди могут открыть. Код читать не нужно. Скажите AI‑помощнику, что хотите построить.

## Если у вас только приглашение в GitHub

Вы ещё не закончили. На компьютере выполните:

```sh
npx vybekiit setup
npx vybekiit create app --web
```

Затем откройте **новую папку**, которую создала команда. Не скачивайте ZIP с GitHub.

## Готовый промпт для AI‑инструмента

Откройте проект в [Claude Code](https://code.claude.com/docs/en/overview), [Codex](https://developers.openai.com/codex/quickstart), [Cursor](https://cursor.com/docs), Grok, Kimi, Roo, [Zed](https://zed.dev/), Kiro, [GitHub Copilot](https://github.com/features/copilot) или любом другом AI‑инструменте и вставьте:

```text
Настрой моё приложение.

Я нетехнический vibe coder. Прочитай AGENTS.md и language.md.
Говори простым языком. По одному действию. Переводи любые ошибки.
Празднуй прогресс. Не сыпь на меня технические шаги.

Начни с первой настройки, пока я не увижу приложение (предпросмотр на компьютере или в интернете).
```

## Начните здесь

Откройте эту папку в AI‑инструменте и скажите:

> **«Настрой моё приложение.»**

Помощник продолжит сам. Он читает инструкции, проводит вас по шагам, которые можете сделать только вы (по одному, простым языком), и выводит приложение в сеть.

## Что можно попросить

- **«Настрой моё приложение»**: первая настройка, пока приложение не будет в сети или в предпросмотре на компьютере.
- **«Добавь платежи»**: начать принимать деньги.
- **«Добавь вход и сохранение данных»**: аккаунты и место, где приложение запоминает информацию.
- **«Что‑то сломано»**: помощник проверит и починит.
- **«Выложи приложение в интернет»**: опубликовать последнюю версию.

Всё. Техническое берёт на себя помощник.
