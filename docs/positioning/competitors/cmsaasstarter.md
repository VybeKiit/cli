# CMSaasStarter (SvelteKit) — Alternative & Comparison

> **Type:** Open-source (MIT) · **Price:** $0 + ~$0–$30/mo infra · **Platforms:** Web only · **Last verified:** 2026-06-27
> Master data: [../comparison-matrix.md](../comparison-matrix.md) · Positioning: [../differentiation.md](../differentiation.md)

**Stack:** SvelteKit, TypeScript, Tailwind + DaisyUI, Supabase, Stripe, Cloudflare Pages + Workers.

**What it is:** A production-ready SvelteKit boilerplate for solo developers building subscription web
SaaS. Ships auth, Stripe billing, a blog engine, landing page, and CI — wired end-to-end and
deployable to Cloudflare Pages (~2.3k★, active June 2026).

**Where it's strong:**
- Zero acquisition cost; zero infra cost up to ~50K MAU on Supabase + Cloudflare free tiers
- Consistently scores 100/100 Google PageSpeed — edge-native and fast
- Complete marketing foundation: landing page, blog, RSS, sitemap, site search, SEO
- Stripe subscriptions fully wired including self-serve billing portal
- Clean four-workflow CI (build, format, lint, tests)

**Where VybeKiit differs / wins:**
- CMSaasStarter delivers code; VybeKiit delivers a guided journey — goal-named skills (go-live,
  setup-payments, doctor) make every decision and verify each step before advancing, so a vibe coder
  ships without touching env vars or a terminal
- Updates arrive as npm version bumps against `@vybekiit/*` packages, never git merges into modified
  files — CMSaasStarter updates require pulling and reconciling diffs
- Session 1 ends with a live, paying app; CMSaasStarter gives a starting point, not a finish line
- One purchase covers web + Expo mobile + WXT extension; CMSaasStarter is web-only, no mobile story
- Lemon Squeezy as MoR handles VAT/global tax; CMSaasStarter is Stripe-only and puts tax on the
  builder
- Provider-agnostic adapters let the agent swap auth/data/payments via one setting; CMSaasStarter
  hard-couples to Supabase + Stripe
- VybeKiit ships i18n (auto-localized + RTL); CMSaasStarter's i18n is an unofficial community branch

**Honest — where CMSaasStarter may be the better pick:**
- Senior/mid developers who read diffs get a fully free, battle-tested foundation with no license cost.
- Builders already committed to **SvelteKit** benefit from its performance and a codebase they own
  entirely — VybeKiit is Next.js/Expo/WXT, not Svelte.
