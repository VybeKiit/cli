# Project Forge — Alternative & Comparison

> **Type:** Open-source (MIT) · **Price:** $0 · **Platforms:** Web only · **Last verified:** 2026-06-27
> Master data: [../comparison-matrix.md](../comparison-matrix.md) · Positioning: [../differentiation.md](../differentiation.md)

**Stack:** Next.js 15, Supabase, Stripe, Drizzle ORM, Tailwind CSS 4, shadcn/ui.

**What it is:** A Claude-Code-native SaaS starter with a built-in autonomous implementation loop
(Ralph++), a spec-kit pipeline, and ~40 reusable SDLC skills. Targets solo founders and Claude Code
power users who want rigorous quality gates and agent-assisted scaffolding from day one. (Very new —
created May 2026, ~0★, no community yet.)

**Where it's strong:**
- Deepest Claude Code integration of any boilerplate: Ralph++ headless loop, sub-agent teams, STRIDE
  threat modeling, architecture fitness tests
- 6-stage CI with duplication detection, dead-code analysis, cognitive-complexity linting
- Full SDLC harness beyond code: ADR framework, maturity scoring, runbook templates, audit logs
- MIT licensed, zero vendor lock-in on the harness

**Where VybeKiit differs / wins:**
- **Decide+Guide vs power-user tooling:** Project Forge assumes you can read a diff, wire env vars,
  and interpret CI failures. VybeKiit's agent makes every decision and translates every error into
  one plain-language fix — no plumbing literacy required. *This is the key distinction:* Project
  Forge's agent serves an **engineer**; VybeKiit's serves a **non-developer**.
- **Live in session 1:** VybeKiit ends onboarding with a live, paying app. Project Forge hands you a
  scaffold; shipping is still your job.
- **Conflict-free updates:** `@vybekiit/*` npm version bumps vs a manual `git pull` + diff resolution.
- **Multi-platform in one bundle:** web + Expo mobile + WXT extension. Project Forge is web-only.
- **Merchant of Record default:** Lemon Squeezy handles VAT/tax; Project Forge wires Stripe directly.
- **Provider-agnostic adapters:** auth/data/storage/email/hosting are swappable; Project Forge is
  Supabase + Stripe throughout with no adapter layer.

**Honest — where Project Forge may be the better pick:**
- Free and MIT-licensed; no purchase friction for developers comfortable owning their stack.
- The Ralph++ autonomous loop and spec-driven quality gates are genuinely ahead of VybeKiit *for
  engineering teams* that want AI-assisted SDLC rigor rather than guided onboarding.
