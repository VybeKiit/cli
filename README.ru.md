# VybeKiit

[![CI](https://github.com/VybeKiit/vybekiit/actions/workflows/ci.yml/badge.svg)](https://github.com/VybeKiit/vybekiit/actions/workflows/ci.yml)

VybeKiit это платный стартовый набор для vibe coders: людей, которые знают, что хотят построить, пользуются AI‑помощником по коду и не хотят учить код до того, как смогут выпустить продукт.

Вы описываете продукт. Помощник следует инструкциям набора, настраивает приложение, чинит поломки и проводит вас по тем немногим шагам, которые можете сделать только вы.

> **Статус:** активная работа над набором. Стартовая точка веб‑приложения, инструкции для помощника и код набора на месте. Живой сценарий покупки и доступа ещё дорабатывается.

## Готовый промпт для AI‑инструмента

Откройте этот проект в [Claude Code](https://code.claude.com/docs/en/overview), [Codex](https://developers.openai.com/codex/quickstart), [Cursor](https://cursor.com/docs), Grok, Kimi, Roo, [Zed](https://zed.dev/), Kiro, [GitHub Copilot](https://github.com/features/copilot) или любом другом AI‑инструменте для кода и вставьте:

```text
Я нетехнический vibe coder и пользуюсь VybeKiit.

Сначала прочитай AGENTS.md и language.md.
Говори со мной простым языком. По одному шагу. Не давай стену команд.
Не жди, что я пойму код.

Помоги мне работать с этим стартовым проектом:
1. Кратко объясни, для чего эта папка.
2. Скажи единственный следующий шаг, который мне нужно сделать.
3. Если нужна настройка, сделай её сам, когда можешь, и веди меня только через клики, которые могу сделать только я.

Начни сейчас: настрой меня так, чтобы я мог строить с AI‑помощником, не изучая код.
```

## Начните здесь

После доступа к VybeKiit создайте стартовую точку приложения (помощник может выполнить это за вас):

```bash
npx vybekiit new web my-app
```

Затем откройте новую папку в AI‑инструменте и вставьте промпт выше или просто скажите:

> **Настрой моё приложение.**

Помощник читает инструкции, которые идут с приложением, и ведёт дальше, по одному шагу.

## Что можно попросить

Не нужно сначала разбираться, как устроен код. Начните с простых запросов:

- **«Настрой моё приложение.»** Первая настройка.
- **«Добавь платежи.»** Начать принимать деньги.
- **«Добавь вход и сохранение данных.»** Аккаунты и сохранённая информация.
- **«Что‑то сломано.»** Проверка и исправление.
- **«Выложи приложение в интернет.»** Опубликовать последнюю версию.

VybeKiit устроен так, что помощник сам выбирает технические шаги и объясняет только то, что нужно вам.

## Что делает набор

- Реальная стартовая точка веб‑приложения.
- Инструкции для AI‑помощников по коду.
- Пути для оплаты, входа, сохранённых данных и публикации.
- Локальная проверка, чтобы помощник убедился, что приложение в порядке, прежде чем идти дальше.
- Общие части, которые набор может улучшать со временем.

От вас ждут описание продукта, просмотр результата и подтверждение шагов в аккаунте или браузере, когда нужно. Не ждут, что вы поймёте код до того, как приложение сдвинется вперёд.

## Что нужно

Нужен [Node.js](https://nodejs.org/en) 20 или новее. Команда настройки использует вспомогательный инструмент VybeKiit.

Чтобы получить файлы купленного приложения, VybeKiit использует небольшой инструмент доступа GitHub. Если он ещё не готов, набор подскажет, что установить или куда войти.

## Для агентов и сопровождающих

В этой папке также лежат инструкции и код, из которых собран сам набор. Если вы агент или сопровождающий внутри проекта, сначала прочитайте:

- [AGENTS.md](./AGENTS.md)
- [CONTEXT.md](./CONTEXT.md)
- [CODE-STYLE.md](./CODE-STYLE.md)
- [LANGUAGE.md](./LANGUAGE.md)

Полезные команды для сопровождающих:

```bash
pnpm install
pnpm build
pnpm test
pnpm typecheck
pnpm lint
```

Инструменты сопровождающих используют [pnpm](https://pnpm.io/) и [Turborepo](https://turborepo.com/docs).
