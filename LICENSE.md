# VybeKiit licensing

This repository is **dual-licensed** by component, matching the Owned vs Maintained split
(see `CONTEXT.md`):

| Component | License | Why |
|---|---|---|
| `packages/*` (published `@vybekiit/*`) | **MIT** | Public, headless logic — free updates double as marketing; nothing secret here. |
| `templates/*`, `cli/`, the agent layer, docs | **Proprietary — VybeKiit EULA** | The paid, owned product. |

## VybeKiit EULA (templates, CLI, agent layer) — summary

A buyer who has purchased access may:

- Build **unlimited** products of their own with the templates, including **commercial** ones.
- Modify the scaffolded code freely (it becomes their code once scaffolded).

A buyer may **not**:

- Redistribute, resell, sublicense, or publish the templates / CLI / agent layer themselves.
- Use them to create a competing starter kit or template product.

Provided **as-is, with no warranty**. Liability is capped at the amount paid. Updates are
best-effort with no compatibility guarantee. Tax/VAT is handled by Lemon Squeezy (Merchant of
Record). Access is revocable on refund.

> Full legal text is finalized before public launch; this summary states intent.
