# Database providers

Database onboarding is **MCP-first** — no Playwright dashboard automation in v1.

| Provider | Path |
|----------|------|
| Supabase | Hosted Supabase MCP + `supabase-vybekiit` platform skill — see `templates/web/.vybekiit/agent/mcp-setup.md` |
| Neon | Neon MCP + `neon-vybekiit` platform skill |
| Firebase | Firebase docs + `firebase-vybekiit` platform skill |

Use `doctor` and `save-data` skills for buyer projects.
